Pixel cam {{version}}

By Ruben Berenguel, 2025

Palettes: tap to switch, long tap for modal

Square button: low/lower res.

Eye button: Blue noise dithering on/off.

Upload button: Use an existing image, or upload a (single) custom palette (Mx32 image composed of 32x32 squares)

Face button: Switch to front camera (and then back).

Long press on the image once taken to save / share it. Sometimes it can fail. If it does, tap twice on the lower resolution and that seems to fix it.

Palettes are from Lospec, you can find the full list in this app's repository

The layout can be somewhat unstable. This is because iOS Safari does not respect preferred orientation lock, so I had to create a responsive layout that looks the same when the phone rotates. This would not happen on Android, but I have to use the same way in both.
